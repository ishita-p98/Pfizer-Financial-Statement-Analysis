# References, sources and acknowledgements

## Primary coursework source
*Financial Statement Analysis — Final Report on Pfizer Inc. (NYSE: PFE)*, MSc Finance group submission, **4 December 2025**, 90 pages.

The report analyzes FY2021–FY2024 and compares Pfizer with **Merck & Co., Eli Lilly and AbbVie**.

## Underlying sources discussed in the report
- Pfizer annual Form 10-K filings, particularly FY2023 and FY2024, for audited financial statements, accounting policies, acquisition and debt notes, and risk disclosures.
- Peer-company annual filings for common-size statements and ratio comparisons.
- S&P Capital IQ analyst EPS consensus figures as quoted in the submission.

These sources are referenced **as described in the report**; the full source filing set and underlying calculation workbooks have not been independently re-audited in this repository.

The original submission PDF is excluded because it contains identifying information. The GitHub material is a newly structured research summary with methodological qualifications. Figures are attributed to the submitted group report and should not be mistaken for an independently verified financial database.
